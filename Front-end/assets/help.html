Help & workflow

How to use and maintain Bookhub.

Use Search to query the live books table, Categories to save browser preferences, and a book page to inspect a database record.

Development rules

Frontend files live under Front-end/assets/. HTML, CSS and browser JavaScript belong there. Supabase public client credentials may be exposed to the browser; service-role keys, database passwords, DATABASE_URL and DIRECT_URL must never be exposed. Prisma is server-side only. When a database field or table changes, update the Supabase migration and Prisma schema together. Pull before editing, review with git diff, then commit and push focused changes.
